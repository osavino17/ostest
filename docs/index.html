03 · Portfolio Planning

Event & sponsorship effectiveness

Average Engagement ROI Index across every attending client — the read to inform next cycle's budget allocation across formats.

Methodology. Scores are relative rankings within this portfolio, not attributed revenue — no touchpoint here is credited with a dollar of client revenue. Engagement ROI Index blends attendance/seniority/event-status with a Business Weight Score (priority tier, active mandates, pipeline, relationship intensity) itself blended by each client's flow-vs-cyclical revenue mix. Figures reflect the sample dataset (sample_data/) used to validate the model. See the repository README for full formulas and instructions for scoring live data.
